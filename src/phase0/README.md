# Phase 0: TensorFlow foundations

This directory contains scripts and introductory materiasl to lear the basic concepts for TensorFlow and ML from scratch.

## Main Files

- `linear_regression_scratch.py`: Linear regression implementation from scratch, without using high level abstractions from TensorFlow. Ideal to understand the mathematical and computational process behind the linear regression.
- `tensor_basics.py`: Excersices and examples to familiarize with tensors, the fundamental data structure in TensorFlow.

## Phase's objectives

- Understand the tensor and how to manipulate it in TensorFlow.
- Implement basic ML algorithms from scratch to understand it's internal workflow.
- Prepare the based for later phases where we'll use advanced TensorFlow APIs.

## Requirements

```bash
pip install -r ../../requirements.txt
```

## Usage

Excecute the scripts directly from terminal:
```bash
python linear_regression_scratch.py
python tensor_basics.py
```
